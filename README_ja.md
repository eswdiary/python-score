# Timeline v6 Color — オーディオトラック タイムライン ビジュアライザー

> 🌐 言語: **日本語** | [繁體中文](README.md) | [English](README_en.md)

DAW からエクスポートしたマーカーファイルとステム WAV を組み合わせて、カラフルな振幅タイムライン画像を自動生成します。楽曲分析・演奏スコア制作・ミックス参照などに最適です。

---

## 機能概要

- DAW（Reaper・Logic Pro・Cubase など）からエクスポートした `marker.txt` を解析
- 各パートに対応するステム WAV を読み込み
- **RMS 振幅**（音量輪郭）と **Spectral Centroid**（スペクトル重心＝音色の明暗）を計算
- スペクトル重心を **HSL 色相**にマッピング（低域 = 暖色オレンジ赤、高域 = 寒色青紫）
- 曲全体を複数行に自動分割（1 行あたり最大 N 個のマーカー）し、A4 横向き PNG / SVG / PDF を出力

## クイックスタート（5 分）

### ステップ 1 — `marker.txt` の準備

1 行に 1 マーカー、番号とタイムコードを ` - ` で区切り、タイムコード形式は `HH:MM:SS.FF`（FF = フレーム番号）：

```
1 - 00:00:00.00
2 - 00:00:33.07
3 - 00:00:48.12
...
```

> **注意**：タイムコード末尾の数字は**フレーム番号**であり、ミリ秒ではありません。デフォルト FPS = 30。スクリプト冒頭の `FPS` 変数を DAW プロジェクトに合わせて変更してください。

### ステップ 2 — ステム WAV の準備

各パートの WAV ファイルをスクリプトと同じディレクトリに配置するか、フルパスを指定してください。

### ステップ 3 — スクリプトの設定

`timeline_v6_color.py` を開き、`PARTS` リストを編集します：

```python
PARTS = [
    {
        'label': 'K',           # パート名（出力ファイル名に使用）
        'audio_file': 'key.wav',
        'show_markers': None    # None = 全マーカーを表示；[1, 3, 5] のように指定も可
    },
    {
        'label': 'P',
        'audio_file': 'pad.wav',
        'show_markers': None
    },
    # 必要に応じてパートを追加...
]
```

### ステップ 4 — 実行

```bash
python timeline_v6_color.py
```

同じディレクトリに以下のようなファイルが生成されます：

```
timeline_v6_K_row_1.png
timeline_v6_K_row_2.png
timeline_v6_P_row_1.png
...
```

## パラメータ一覧

### グローバルパラメータ

| パラメータ | デフォルト | 説明 |
|-----------|-----------|------|
| `FPS` | `30` | マーカータイムコードのフレームレート（DAW 設定と一致させること） |
| `MARKERS_PER_ROW` | `6` | 1 行あたりの最大マーカー数 |
| `INPUT_MARKERS` | `'marker.txt'` | マーカーファイルのパス |
| `OUTPUT_PREFIX` | `'timeline_v6'` | 出力ファイル名のプレフィックス |

### 出力フォーマット

| パラメータ | デフォルト | 説明 |
|-----------|-----------|------|
| `EXPORT_PNG` | `True` | PNG を出力 |
| `EXPORT_SVG` | `False` | SVG（ベクター画像）を出力 |
| `EXPORT_PDF` | `False` | PDF を出力 |
| `PNG_DPI` | `300` | PNG 解像度（dpi） |

### ページレイアウト

| パラメータ | デフォルト | 説明 |
|-----------|-----------|------|
| `PAGE_W` | `11.69` インチ | ページ幅（A4 横向き） |
| `ROW_H` | `2.0` インチ | 1 行の高さ |
| `PAD_LEFT / PAD_RIGHT` | `0.6` インチ | 左右の余白 |
| `PAD_TOP / PAD_BOTTOM` | `0.5` インチ | 上下の余白 |

### 振幅カーブ

| パラメータ | デフォルト | 説明 |
|-----------|-----------|------|
| `RMS_FRAME_LENGTH` | `2048` | RMS 解析ウィンドウサイズ（samples） |
| `RMS_HOP_LENGTH` | `512` | RMS 解析ホップ長（samples） |
| `SMOOTH_SIGMA` | `5` | ガウシアン平滑化の強度（大きいほど滑らか） |
| `AMP_HEIGHT` | `0.5` | 振幅カーブの最大高さ（インチ） |
| `AMP_ALPHA` | `0.85` | カラーバンドの不透明度（0=透明、1=不透明） |

### カラーマッピング（HSL）

| パラメータ | デフォルト | 説明 |
|-----------|-----------|------|
| `HUE_LOW` | `0.04`（≈ 14°、オレンジ赤） | 低域の色相 |
| `HUE_HIGH` | `0.67`（≈ 240°、青紫） | 高域の色相 |
| `HSL_SATURATION` | `0.65` | 彩度（0=グレースケール、1=フルカラー） |
| `HSL_LIGHTNESS` | `0.50` | 明度 |
| `RMS_SILENCE_THRESHOLD` | `0.02` | 無音閾値。これ以下のセグメントは透明になる |
| `CENTROID_HZ_MIN` | `None` | カラーマッピングの下限（Hz）；`None` = 自動検出 |
| `CENTROID_HZ_MAX` | `None` | カラーマッピングの上限（Hz）；`None` = 自動検出 |

## 応用設定

### 特定のパートに一部のマーカーのみ表示

```python
{
    'label': 'R',
    'audio_file': 'rhythm.wav',
    'show_markers': [1, 2, 5]   # マーカー 1・2・5 の位置にのみ目盛り線を描画
}
```

### カラーマッピング範囲を固定（複数パートの統一基準）

パート間で周波数範囲の差が大きい場合、固定範囲を設定してカラーを比較可能にできます：

```python
CENTROID_HZ_MIN = 200   # 全パートの色の下限を 200 Hz に固定
CENTROID_HZ_MAX = 8000  # 全パートの色の上限を 8000 Hz に固定
```

### カラースキームのカスタマイズ

色相範囲は自由に設定できます（0.0–1.0 が HSL カラーホイルの 0°–360° に対応）：

```python
HUE_LOW  = 0.33  # 緑（低域）
HUE_HIGH = 0.83  # ピンク紫（高域）
```

## 出力ファイル名の規則

```
{OUTPUT_PREFIX}_{label}_row_{row_idx}.png
```

例：`timeline_v6_K_row_1.png` = パート K のタイムライン 1 行目。

各行の時間範囲はマーカーから自動的に決定されます：
- N 行目の開始点 = `(N-1) × MARKERS_PER_ROW + 1` 番目のマーカーの時刻
- N 行目の終点 = 次の行の最初のマーカーの時刻（最終行はオーディオの末尾まで延伸）

## よくある質問

**Q: 実行時に `FileNotFoundError: marker.txt` が発生する**
→ `marker.txt` が実行ディレクトリにあるか確認するか、`INPUT_MARKERS` にフルパスを指定してください。

**Q: `FileNotFoundError: key.wav` が発生する**
→ 各 `audio_file` のパスが正しいか確認してください。WAV はモノラル・ステレオ両方対応（librosa が自動でモノラルに変換）。

**Q: タイムコードがずれている**
→ `FPS` が DAW プロジェクトのフレームレートと一致しているか確認してください（一般的な値：24・25・30）。

**Q: 色がすべて同じかグレーに見える**
→ `HSL_SATURATION`（彩度）を上げるか、`RMS_SILENCE_THRESHOLD` を調整してください。`CENTROID_HZ_MIN / MAX` を固定するとカラーコントラストが改善することもあります。

**Q: 振幅カーブが太すぎる/細すぎる**
→ `AMP_HEIGHT`（カーブの高さ）と `SMOOTH_SIGMA`（平滑化の強度）を調整してください。

## marker.txt フォーマット（DAW エクスポート参考）

対応フォーマットの例（Reaper の Region/Marker Manager からエクスポートして整理）：

```
1 - 00:00:00.00
2 - 00:00:33.07
3 - 00:00:48.12
4 - 00:00:52.01
```

- 番号とタイムコードは ` - `（スペース-ハイフン-スペース）で区切る
- タイムコード形式：`HH:MM:SS.FF`（FF はフレーム番号、ミリ秒ではない）
- 空白行は自動的に無視される
